# gradebook-database

This is a Database project from CSC4480 (Principles of Database Systems) intended for use with Oracle SQL Developer. The project is a gradebook for use of calculating course grades based on assignment grades. The gradebook allows for grade categories of different weights, such as Exams 50%, Homework 25%, and Quizzes 25%.

## How to use
Open the SQL file in Oracle SQL Developer. Connect to a database. Execute by pressing the Run Script button.
